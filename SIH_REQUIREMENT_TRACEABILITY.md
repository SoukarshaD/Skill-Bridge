# SIH Requirement Traceability

This document traces the original Smart India Hackathon (SIH) 2026 requirements implemented in the SKIL BRIDGE platform. This constitutes the final compliance audit.

| # | SIH Requirement | Required Capability | Actual Implementation | Evidence | Status | Remaining Work |
|---|---|---|---|---|---|---|
| A | Student Skill Development | student skill profile, technical skills, soft skills, aptitude, strengths, gaps | Handled natively. Students take technical/soft/aptitude assessments which automatically updates their `StudentSkill` records in the `StudentProfile`. | `backend/src/modules/assessments/assessments.controller.ts`, `prisma/schema.prisma` (`StudentSkill`) | FULL | None |
| B | Skill Assessment | questionnaire/assessment, proficiency levels, assessment result persistence | The Assessment module supports dynamic MCQs. Test logic strictly validates answers securely on backend. Scoring is isolated. | `backend/src/modules/assessments/assessments.controller.ts` (`submitAssessment`) | FULL | None |
| C | Skill Profiling | Profiling base on assessment | Yes, when assessments complete, skills mapped to questions are aggregated and update student profile. | `backend/src/modules/assessments/assessments.controller.ts` | FULL | None |
| D | Skill Gap Analysis | Gap relative to industry standard | The Career Guidance module and institutional analytics compute the exact delta between student's proficiency and required industry baseline. | `backend/src/modules/analytics/analytics.controller.ts` (`getSkillGaps`) | FULL | None |
| E | Personalized Learning | Learning recommendations based on gaps | `LearningResource` mapped to `SkillTaxonomy`. When gap is identified, student receives recommendations natively mapped in database. | `frontend/src/app/student/career/[roleId]/page.tsx` | FULL | None |
| F | Career Guidance | Explainable recommendation | Career pathway computes readiness score out of 100% comparing student's `StudentSkill` with `CareerRoleSkill` weights. | `backend/src/modules/career/career.controller.ts` | FULL | None |
| G | Internship | Centralized discovery, matching, milestones | The Opportunity model uses `OpportunityType.INTERNSHIP`. Includes applicant ranking, shortlisting, milestone creation (`InternshipMilestone`). | `backend/src/modules/internships/internships.controller.ts` | FULL | None |
| H | Placement | Jobs, application state transitions | Handled by `OpportunityType.JOB` and `ApplicationStatus` (APPLIED -> SHORTLISTED -> OFFERED -> ACCEPTED). Institutional analytics tracks placements. | `backend/prisma/schema.prisma` | FULL | None |
| I | Recruitment Tracking | Application tracking | Students have trackable application histories in dashboard. Organizations manage via kanban-style applicant ranking. | `frontend/src/app/industry/opportunities/[id]/page.tsx` | FULL | None |
| J | Industry Learning / Training | FDPs, Workshops, Industrial Training | Organizations create `ProgramType.FDP`, `WORKSHOP`, `INDUSTRIAL_TRAINING`. Academicians/Students can register. | `backend/src/modules/programs/programs.controller.ts` | FULL | None |
| K | Academician Portal | Faculty internship, consultancy, research | Academicians have dedicated RBAC role, profile, and UI routes (`/academician/*`) to browse FDPs and receive proposals. | `frontend/src/app/academician/*` | FULL | None |
| L | Industry-Academia Collaboration| Mentorship, challenges, projects, research | Comprehensive `Collaboration` model handles Proposal -> Review -> Accept state machine for Consulting/Research. | `backend/src/modules/collaborations/collaborations.controller.ts` | FULL | None |
| M | Institutional Analytics | Skill gaps, placement, academician engagement | The `/admin/dashboard` aggregates data exactly as required, pulling readiness percentages, accepted offers, and FDP/collaboration counts. | `backend/src/modules/analytics/analytics.controller.ts` | FULL | None |
| N | Digital Portfolio | Verified vs Self-Reported, Evidence | Student `PortfolioItem` supports `VERIFIED` and `SELF_REPORTED` status natively. Integrated with document uploading. | `backend/prisma/schema.prisma` (`VerificationStatus`) | FULL | None |
| O | RBAC / Security | JWT Auth, Role Isolation | Strict multi-role (`STUDENT`, `INDUSTRY`, `ACADEMICIAN`, `ADMIN`). Protected routes natively in Next.js middleware and Express. | `backend/src/middleware/auth.middleware.ts` | FULL | None |
| P | Secure Documents | File validation, Secure URLs | Integrated Document model utilizing protected signed URLs, blocking cross-user and cross-org access natively. | `backend/src/modules/documents/documents.controller.ts` | FULL | None |
| Q | Apprenticeship | Apprenticeship specific opportunities | `OpportunityType.APPRENTICESHIP` implemented in DB schema and fully exposed on both frontend Industry POST and Student GET flows. | `backend/prisma/schema.prisma` | FULL | None |
| R | External Integrations | Third-party systems | Original SIH spec is highly internal workflow-focused. Real third-party API integration (e.g. LinkedIn, AWS S3 real bucket) is mocked for demo. | - | OPTIONAL / FUTURE | Add external AuthProviders/Webhooks |
| S | Overall ecosystem | End-to-end integration | The entire student-to-job, industry-to-academician workflow completes without duplicate tables or hacky workarounds. | Comprehensive e2e flow | FULL | None |
